# Keep Right - *RPH Plugin*

A *RAGE Plugin Hook* plugin that makes vehicles in the left lane in front of the player move to the right.

Available on [gta5-mods.com](https://www.gta5-mods.com/scripts/keep-right) and [lcpdfr.com](https://www.lcpdfr.com/downloads/gta5mods/scripts/55899-keep-right/).


## Configuration
You can adjust some values in the `.ini` file :
- How often to check for vehicles in front,
- Whether the effect should affect other emergency vehicles or not,
- Whether the effect should apply to big vehicles (truck, bus, ...) when the player has their siren turned on*,
- The additional probability that the vehicle will change lanes if: 
	- it is a big vehicle, 
	- the player is in an emergency vehicle, 
	- or the road is not a highway.

*By default, big vehicles do not react to sirens; this allows them to react, but it might conflict with other mods.
